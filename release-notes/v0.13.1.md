## 设置即时刷新 / Immediate settings refresh

- 修复设置已保存和生效，但开关与下拉框仍显示上一次选择的问题。修改后立即刷新显示，无需切换页面或重新打开设置。
- 保留现有设置和便笺数据，并同步其他组件修改的设置。
- 新增嵌套设置行的刷新回归测试。本机测试通过；用户报告的 macOS 14.6.1 实际交互仍待反馈验证。

- Settings now publish edits immediately instead of waiting for storage notifications, addressing stale toggle and picker values.
- Existing preferences and notes are preserved; changes made by other components remain synchronized.
- Added regression coverage for nested settings rows. Local checks pass; confirmation on the reported macOS 14.6.1 installation is still pending.
