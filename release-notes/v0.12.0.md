## 新功能 / What’s new

- **选择显示器**：设置 → 通用，可选跟随鼠标、主显示器或指定显示器。指定显示器断开时暂用主屏，重连后自动恢复；固定屏幕时拖回便笺也不会把绳子移到其他屏幕。
- **自由摆放**：沿绳拖动便笺不再吸附固定格子，附近卡片自动让位。落点会保存并随屏幕宽度调整；支持撤销摆放、备份恢复和拖到两端滚动。
- **保持显示**：关闭「自动收起绳子」后，绳子持续显示；仍可点击菜单栏图标或使用快捷键手动收起。
- 中英文设置、使用说明同步更新，兼容已有便笺数据。

- **Choose a display**: follow the pointer, use the main display, or select a specific display in Settings → General. A disconnected display falls back to the main display and is restored when reconnected. Returning a note respects the fixed-display preference.
- **Position notes freely**: drop anywhere along the string, with nearby cards making room. Positions persist and adapt to display width, with undo, backup support, and edge scrolling while dragging.
- **Keep the string visible**: turn off Auto-hide string. Manual hiding through the menu bar icon or shortcut remains available.
- Updated English and Simplified Chinese settings and documentation; existing note data remains compatible.

## 下载 / Downloads

macOS 13 or later. Apple Silicon: **arm64**; Intel: **x86_64**. DMG and ZIP packages include SHA-256 checksum files.

```sh
brew update
brew upgrade --cask TD21forever/tap/string-notes
```

应用使用临时签名，尚未经过 Apple 公证；首次启动可能需要在系统设置 → 隐私与安全中允许打开。
The app is ad-hoc signed and not notarized. macOS may require first-launch approval in System Settings → Privacy & Security.

## 验证范围 / Validation

通过显隐与摆放逻辑、数据持久化、备份、编辑器、更新与本地化回归检查，并完成单屏原生窗口和中英文设置布局检查。真实外接屏插拔尚未实测。

Regression checks cover visibility, placement, persistence, backups, editing, updates, and localization. Native-window and bilingual settings checks passed on a single display. Physical external-display unplug/reconnect testing remains outstanding.
