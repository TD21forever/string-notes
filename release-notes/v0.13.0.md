## 应用内更新 / In-app updates

- 接入 Sparkle：在应用内下载、校验、安装更新并重新打开，无需再手动替换应用。
- 更新源和安装包使用独立 Ed25519 签名，下载完成后验证来源及完整性。Apple Silicon 和 Intel 使用独立更新源。
- 退出前保存全部便笺；保存失败或输入法仍在选词时阻止退出。更新完成后恢复打开的便笺。
- 保留自动检查开关并迁移旧设置，安装仍由用户确认。手动下载是备用入口。

- Sparkle downloads, verifies, installs updates and relaunches the app in place.
- Both update feeds and archives are Ed25519 signed, with separate Apple Silicon and Intel feeds.
- All notes are saved before quitting. Save errors and unfinished input-method composition prevent quitting. Open notes return after the update.
- The automatic-check preference is preserved. Installation requires user confirmation, with manual download as a fallback.

## 首次迁移 / One-time migration

**0.12.0 及以前版本需要最后手动安装或通过 Homebrew 升级一次。装上 0.13.0 后，后续新版可在应用内安装。**

**Versions 0.12.0 and earlier need one last manual install or Homebrew upgrade. After installing 0.13.0, future versions can be installed in the app.**

```sh
brew update
brew upgrade --cask TD21forever/tap/string-notes
```

macOS 13+. Apple Silicon / Intel: DMG and ZIP available. Ad-hoc signed, not Apple-notarized; first installation may require approval in System Settings → Privacy & Security. 更新签名不等于 Apple 公证；首次安装的系统提示仍可能出现。
