## 中文

- 新增英语界面：设置 → 通用 → 语言，可选择跟随系统、简体中文或 English，重启后生效，已有便笺正文保持不变。
- 新增「检查更新…」入口：检查 GitHub Release、查看发布说明并下载适合当前 Mac 的安装包。
- 可选启动时自动检查，每天最多一次；支持失败后重试。
- 更新仍需下载后退出应用并手动替换，不会自动安装。

适用于 Apple Silicon 和 Intel Mac、macOS 13 及以上。M 系列请选择 arm64，Intel 请选择 x86_64；可使用 DMG 拖拽安装，或下载 ZIP 后解压，将「绳上便笺.app」替换到应用程序目录。此版本仍为未公证的预览版。

## English

- English and Simplified Chinese UI, with a system-language default. Choose Settings → General → Language and restart. Existing note content stays unchanged.
- Check GitHub releases from “Check for Updates…”, read release notes, and download the package for your Mac.
- Optional automatic checks on launch, at most once per day, with retry after network errors.
- Installation is manual: quit the app and replace it in Applications after downloading.

Requires macOS 13 or later on Apple Silicon or Intel. Choose arm64 for Apple Silicon and x86_64 for Intel; DMG and ZIP downloads are available. This is an unnotarized preview release.


Intel 安装包通过交叉编译、签名及映像校验；GitHub Intel macOS 环境运行存储、编辑、更新和语言测试。尚未完成 Intel 实机交互验收。

Intel packages are cross-compiled and pass signature and image checks. Storage, editing, update, and localization tests run on GitHub Intel macOS. Interactive testing on a physical Intel Mac remains outstanding.
